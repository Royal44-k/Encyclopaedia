# V6：人物动作、声音与完整舟游

2026-11-12。用户要求直接实施，并明确禁止付费工具。沿用现有作品，所有新产物保存本地，旧版保留。

- 美术：用内置图像能力制作皮肤/指节/古代宽袖细节的手部素材，替换几何拳头；同一握持素材保持工具接触点稳定。生成接口若要求额外付费则不使用。Canva 当前返回需重新认证，本轮不依赖该连接。
- 点茶：保留真实拖动碾、倒、拂。完成后支持双手捧盏，近身抬起至视线下沿的嘴边，微倾、两次极轻吞咽位移、缓缓放回。第一人称不额外在画面中画嘴。
- 题扇：完成三笔后，手从下方握住扇柄，抬扇到眼前，三次由慢到快再收缓的腕部扇动；扇面角度/透视与袖摆不同步，环境柳叶、水纹和暖光响应微风。
- 声音：已只读确认 HeyGen 当前为 free 计划。公共中文 instant 声线，一次合成连续旁白，按可靠时间点分段。音乐用本地离线合成导出真实 WAV 音频，按景切换与交叉淡化；旁白降低配乐，结束恢复。浏览器首次交互后启用，关闭偏好持久化。
- 船家：气泡锚定船家屏幕坐标，移动时跟随，读完自动消失；不会固定在右上角。过桥游戏结束或普通乘舟完整靠岸后，短暂收束并自动进入乌龟潭。
- 水鸟：保留每只鸟的世界坐标、速度、朝向和警觉状态；船进入警戒距离时逐渐转向水岸，靠近时加速，远离后减速。岸界约束，不穿岸、不突然横跳。
- 船篷：删除悬空半圆支架，保留坐在篷下的顶缘、内侧覆面和依附篷面的细骨；船尾视角按位置显示前方篷顶。
- 靠岸：用船体碰撞包络而非仅相机点检查离岸距离。最后一段减速，沿码头平行贴靠，保持护舷间隙，停稳后架跳板，再起身离船。

验证包括：真实音频文件可解码播放、音量衰减、第一人称喝茶完整时序、执扇握柄对齐、气泡随人及计时消失、两种舟游进入乌龟潭、水鸟避让距离、船体到岸/埠的最小间隙和原有交互回归。

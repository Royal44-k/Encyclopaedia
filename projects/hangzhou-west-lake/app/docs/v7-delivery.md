# V7 · 音乐与真实握持专项改进

本轮针对用户指出的重击配乐、空握摇橹、执扇脱手、喝茶前后换杯问题修复。

- 真人古琴独奏《平沙落雁》，Charlie Huang，CC BY 2.5。全站连续播放完整长曲，移除原短拨弦调度及晴景低频底噪；原录音去直流、峰值控制、首尾淡化仅在播放缓冲区完成。网站保留作者和许可链接。20 段原旁白保留。
- 手与扇柄使用同一复合素材和完整坐标变换；题扇时已在手中，三次轻摇后回到相同姿势，重播不跳位。
- 双手与橹杆使用同一握持图层，围绕固定支点连续运动；独立相位平滑启停，停止后保留原位置。航行、避鸟与靠岸逻辑保留。
- 现代玻璃杯、宋代建盏在桌面与手中保持相同形状、尺寸注册和锚点。0–0.8 秒伸手，0.8–2.4 秒举杯，2.4–3.5 秒轻抿，3.5–5.1 秒放回，5.1–6.1 秒松手。杯子在握稳前不移动；释放前已回到桌面。饮用时底部控制淡出，顶部返回仍可用。
- 碾轮、汤瓶、茶筅改为真实握持复合素材；碾槽固定，滚轮与双手统一移动；水流起点绑定实际壶嘴。新增长袖连续网格延展，手掌和器物保持原坐标。
- 去掉覆盖手部的大面积浅色底部遮罩，保留小范围文案背景。

摇橹运动研究依据：[大澳文化协会传统舢舨教育项目](https://www.taioca.org/about-3) 的橹榫支点、橹绳与推拉转腕八字轨迹。本项目参考通用摇橹机械关系，画面仍是艺术化第一人称重建，不声称与真实西湖船型尺寸完全一致。

音乐来源、许可、波形和声道验证详见 [音乐调查](research/2026-11-12-music-v7.md)。新增握持素材由内置图像工具编辑，原始图保留；未调用付费外部媒体服务。前景是写实图像分层和连续动画，并非真人视频或完整三维手部动作捕捉。

验收日期：2026-11-13。38 项单元测试覆盖杯子接触后才移动、放回后才释放、手机杯口高度、橹杆不截断、固定支点及连续启停等；完整 UI 流程已跑通手动碾茶/注汤/击拂、品饮、题扇、两条过舟入口、避鸟、减速靠岸与离船。六种视口检查无控件越界或相互重叠。桌面与手机关键帧已目视复查，另检查了袖摆网格连续性和空手层无杯沿残片。浏览器无脚本错误或资源缺失。开发验收记录位于 verification/v7，静态包不包含开发脚本。没有进行完整人耳听审，不将解码/波形验证等同于听完曲目。

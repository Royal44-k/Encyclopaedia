# V2 实施与复核记录

需求：现代十景具体体验、真实景观与文化调研、八段水墨穿越、不同人物和关节动作、完整登船坐下离船、更广视野与雨雪。

已完成调研报告、14 个独立观景/茶室/坐姿视角、断桥冬景、48 位居民、独立主角四姿态图集、开敞船篷与无固定桨船体。新资源仅做图集透明切片和 WebP 运行编码；原图保留在生成目录，提示词和来源映射保存在 assets/v2。

实现范围依 docs/v2-design.md。Ruling：维持无需运行依赖的 Canvas 2D 架构，以受限第一人称镜头路线和专属活动构成画境；没有把图片镜头移动表述为测绘三维自由漫游。该边界写入 README 和产品湖山小笺。

独立最终审查发现并已修正：
- 雨滴负余数导致长时间离屏：改为正模数，覆盖 0/40/100/3600 秒测试。
- 断桥雪→雨→晴底图滞留：状态与资源切换一起处理。
- 坐下/登塔后重走未复位：重新进入当前场景起点，取消旧异步回调。
- 竖屏全卷缩放下限错误：按屏幕宽高真正适配整幅长卷。
- 船夫手臂未跟桨：移除静态手臂绘制区域，双臂关节跟随同根桨握点，入水相位附涟漪。

视觉复核额外修正：茶杯被底部操作遮住、船中对白遮挡主角、居民初始过度重叠。三者已调整。

验证记录：
- 12 项 Node 行为测试通过。
- scripts/acceptance-v2.cjs：十景操作、行走停步、龙井全过程、八段进度、48 独立角色、全卷、全套舟行阶段、移动控制、资源和脚本错误检查通过。
- scripts/regression-v2.cjs：坐姿重置、塔顶重置、雪雨晴、近看重置、手机真全卷和划桨渲染通过。
- 最终交付前补测宋代点茶、暂停/失焦、截图导出与完整重播，结果保存在 verification/v2。

本项目的天气、人物动作与画面属于艺术化模拟；并不宣称满足真实物理仿真、精准场地复刻或参考仓库全部子游戏的范围。

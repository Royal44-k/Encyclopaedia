# V4 · 一湖三境

本轮用户要求主动补足参赛作品的设计、创新与完成度，明确交由实现者判断。继续使用现有静态 ES 模块 / Canvas / WebAudio，不引入付费生成平台，不覆盖 V3 交付包。

## 审视与选择

V3 的功能数量已不少，但体验散、缺少开场到收卷的叙事，手机工具偏密，乌龟潭存在重复树阵、规则岸坡和硬质几何感。本轮选择“有导演节奏的六幕导览 + 自由游览”双路径，而非继续堆砌景点数量。导览必须调用实际场景和互动，能暂停、前后选幕与接手，不能用静态宣传幻灯片替代。

1. **一湖三境**：堤岸休憩、荷风听雨、墨滴入宋、宋人点茶、湖西舟行、秋月收卷。以实际交互组成约两分半的艺术蒙太奇，四时跨景不称为现实单日路线。音频由用户选择开启；切后台暂停计时；减弱动态时改为手动换幕。
2. **湖山寻路**：北向上的原创示意图，呈现湖、城、堤、岛、十景与湖西秘境的相对关系；标注非导航，点击景点可读一段文化信息后进入。不是精确地理地图。
3. **寄一张西湖**：以当前实际画面为图，选择横/竖画笺，题写短句与署名，保存 PNG。纯本地生成；原始景色和用户文字不上传。
4. **自然水岸**：连续扰动岸缘、分层树丛、低灌草本、石岸接水、近景芦苇、桥前后遮挡、水光与少量水鸟，消除等距树阵。维护可通行航道与景行桥的石拱形态。
5. **手机观景**：次级工具收进可展开的“游湖工具”；保留主要行动、返回和声音。手记收录区分古今茶事、题扇、湖西舟行；完整体验后收录。
6. **展演稳定性**：避免离开场景仍响应键盘；错误可重试；检查快速切幕和模态焦点、低动态、移动端、下载结果和控制台。

## 设计语言

沿用作品规定的东方长卷材料，不另换模板。主色：绢纸 #e8ddc4、湿墨 #253c35、湖绿 #6b8b79、柳青 #a6b78b、印泥 #98563f、月白 #f7f1e4。标题楷体、正文宋体，辅助操作使用系统无衬线提高小尺寸辨识。标志性设计是“六片书签构成的导览卷签”：数字只表达真实顺序。主画面保持安静，最多一个主要操作焦点。

## 事实边界与来源

- UNESCO《West Lake Cultural Landscape of Hangzhou》：三面云山一面城、堤岛与人文营造、十景的诗意命名及人地关系。本轮新文案是概括，不复制大段原文。https://whc.unesco.org/en/list/1334/
- 杭州发布 / 西湖风景名胜区管委会《西湖边的池潭还有这些用途？》：乌龟潭连接景行桥、西里湖与浴鹄湾；2003 年保护工程恢复水面，湿地与水生植物。https://hznews.hangzhou.com.cn/chengshi/content/2023-02/12/content_8469034.htm
- 其他具体十景、桥体、宋茶来源沿用并链接 V2/V3 已查证研究。
- 空间压缩、镜头、配乐、旁白字幕和画笺都是艺术表达。未取得比赛正式章程、评审标准、指定分辨率与署名规范，不自行宣称已满足官方参赛资格。

## 验收

真实浏览器走完六幕；暂停不推进、切换不串景、接手可继续操作、后台不跳幕；图上选景正确；画笺题字安全、PNG 可解码；手机主要操作可见且不横向溢出；旧墨染、坐椅、点茶和过舟不回归。实截图评价画面，测试通过不能替代视觉判断。

# 杭州西子湖：今夕入画

用户选择当前线上主体验为基准，并明确：首屏是现代西湖十景，突出杭州城市、东方韵味与江南水乡融合；点击穿越，从静态长堤画卷进入动态宋韵西湖与市井生活。参考项目的布局、设计点、交互操作是对照目标。

## 实现决定

独立实现静态前端，使用原创生成画卷和人物，不复制参考仓库代码、图片或音频。参考仓库公开但未授予复用许可。采用原生 ES modules + Canvas 2D；水面采用独立画布的连续波纹、倒影与点击涟漪，穿越采用画面采样粒子与相机推进。此技术选择由实现者作出，验收以实际画面和行为为准。

比较过的方式：直接改原仓库需额外复用授权；完全三维建模会改变手卷绘画质感；选择原创位图分层与实时动画以保持参考体验和素材可控性。

## 场景与视觉

现代首页：淡绢色纸张、细笔淡彩、青绿远山、左上题名、右侧小型说明、底部十景导航。长卷里安排白堤断桥、孤山亭阁、苏堤曲院、湖上三潭、雷峰与南屏山景，杭州现代建筑只在远景克制出现。十景是传统十景在当代的呈现，不冒充真实地理地图。

宋韵入画：独立古代画卷，包含连续堤岸道路、石桥、茶肆、商摊、柳树、画舫与远山塔影。人物、船、水、天气、交互标记独立绘制。沿湖游览、点击走到、相机跟随、拖动浏览、缩放、全景回看。

色彩：绢纸 #e8ddc4，浓墨 #34483f，青绿 #607d6d，远山 #99aca1，赭石 #986047，灯火 #edbe72。题名使用书法/楷体优先，正文宋体，操作文字简洁。

## 可操作体验

- 现代十景导航、场景短注、全景与局部查看。
- 穿越分阶段推进、粒子散开重聚、可拖动进度、可跳过、可退出；完成后遇到引路人，选择随行或自行入画。
- 古代左右行走、点地前往、自动游览、相机跟随、全景、双击和滚轮缩放、触摸拖动。
- 招船、走向码头、登船、游湖、靠岸、下船；水面点击涟漪。
- 茶肆品茗、桥头观鸟、人物短对话；故事事件以西湖为主题；游历收集与画稿保存。
- 春夏秋冬、昼夜、时雨，统一动画时钟与暂停；环境声默认关闭，通过用户手势开启。
- 键盘操作、移动端布局、减少动态设置、页面失焦暂停、资源失败重试。

## 验收

实际浏览器验证现代首屏、穿越、古代入画、人物行走、场景导航、船状态、天气季节、收集保存、返回现代与移动端。生成截图检查遮挡与画面比例；测试状态转换与旅程完成等核心行为。原项目全量实验性页面不属于用户选择的范围，新增功能的对齐状况在 README 中如实说明。

# West Lake V3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 实现差异化十景、连续落座、乌龟潭空间船游、黑墨转场和分景音乐。
**Architecture:** 保留 ES modules / Canvas2D，增加独立透视环境和体验状态模块，远景画稿与真实坐标近景结合。
**Tech Stack:** JavaScript, Canvas, WebAudio, Node tests, Playwright WebKit.
**Spec:** docs/v3-design.md

## Global Constraints
- 现代默认、直立江南诗韵印章、右上展卷、保留旧桥影游戏。
- 事实可追溯；不购买 Runway；无新第三方运行时依赖。
- 键盘/触屏、减弱动态、失焦暂停、快速换景不会串状态。

## Review Focus
- 坐下/站起连续且可重置；异步换景不能污染当前场景。
- 船桥相对移动、出桥遮挡恢复、船尾与座舱视角互斥。
- 十景互动结果实际可见，手机按钮可达。
- 静音与页面失焦不残留旋律，切景及时更换配乐。
- 旧长卷故事、上下船、天气和茶事不回退。

# West Lake Implementation Plan

> **For agentic workers:** Execute with superpowers:executing-plans in this session.

**Goal:** Build a runnable modern-to-Song West Lake handscroll experience matching the chosen reference's interaction structure.

**Architecture:** Original layered art, an independently written Canvas renderer, state-based walking/boat/story controls, and DOM controls. Static files served by a small local Node server.

**Tech Stack:** HTML, CSS, JavaScript ES modules, Canvas 2D, Web Audio, Node built-ins.

**Spec:** ../specs/2026-11-09-west-lake-design.md

## Global Constraints

- Modern initial view; ancient dynamic view after crossing.
- Original artwork and code; no reference assets in shipped app.
- Chinese UI; touch, keyboard, reduced motion and pause supported.
- Reference test screenshots remain outside app distribution.

## Review Focus

- Returning home during crossing cancels animations and restores input.
- Dragging does not trigger click walking; clicks outside the walkable ground do not move actors into water.
- Boat transitions preserve valid actor positions; pause stops boat progress.
- Resizing preserves selected scenic position; mobile controls stay reachable.
- Missing art yields recovery UI; stored collection is validated before use.

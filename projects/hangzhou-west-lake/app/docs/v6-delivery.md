# 杭州西子湖 · V6 交付

本轮在 V5 基础上，替换第一人称手部与茶器、增加六秒捧盏轻饮、写实绢扇与自动执扇送风；原有直接拖动碾茶、倾注、击拂和按住过舟保留。

17 段配乐与 20 段中文解说已保存为站内 WAV。首次操作后开始声音，用户可分别关闭、重听；解说时配乐降低，离开场景停止旧解说。免费计划及素材来源见本轮研究记录和 assets/v6/sources.json。

船家对白跟随人物坐标，解说结束后消失。过舟及普通乘舟完成后自动进入乌龟潭。水鸟保存自己的位置、速度与警觉状态，逐步避让；船在鸟群前减速。删除悬空半圆支架，保留覆篷内缘。靠岸以整船包络检查，沿码头平行减速，停稳铺跳板，连续起身上岸。10,001 个路径采样的最小净距约 0.314 个场景单位（内部以米标度创作，不是实地测绘）。

## 验证记录

- npm run check：30 项单元与资源测试。
- scripts/acceptance-v6.cjs：音频设置、真实手势点茶、完整喝茶、题扇扇风、过舟转入乌龟潭、水鸟避让、完整靠岸上岸、普通乘舟自动衔接，以及浏览器错误和资源检查。
- scripts/layout-v6.cjs：320×740、390×844、667×375、768×1024、1024×768、1440×960 的布局边界与重叠检查。
- 浏览器截图和详细运行结果存于 verification/v6；静态包不包含开发验收脚本和大幅原始 PNG。

## 使用

开发预览：http://127.0.0.1:4173/ 。交付包解压后需 Node.js 22+，双击“启动预览.cmd”，使用 http://127.0.0.1:4174/ 。不要直接双击 HTML。也可把 index.html、styles.css、src、assets 放到静态服务器根目录。

写实手部采用透明素材与连续动画组合，场景仍是 Canvas 艺术化空间，不是实拍 VR 或动作捕捉。音频已做播放与数据验证，普通话读音和韵律仍需人工完整试听。尚未公开部署或代为提交比赛。

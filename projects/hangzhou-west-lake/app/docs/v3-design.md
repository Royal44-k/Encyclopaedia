# 杭州西子湖 V3 · 移步换景与湖西秘境

用户目标：供杭州城市文化比赛展示；保留现代入画—宋韵长卷框架，以真实文化为依据改善浅层交互。用户已要求主动设计并执行，无需重复确认。

## 设计决策

- 保留宣纸、工笔淡彩、低饱和湖青的既有视觉。颜色：墨黑 #090a09、柳青 #536b4f、水碧 #799b8c、纸白 #eee7d5、朱砂 #a74738。宋体展示标题，无衬线操作字、Georgia 英文。
- 主记忆点是“卷尽还有湖”：从宋韵长卷乘舟抵岸，主动选择进入现代乌龟潭，在实际有深度的水道中行舟。
- 新增 Canvas 透视场景层，统一世界坐标、相机眼高/前进/横移/转向。近景路面、石栏、树、椅、水岸和桥梁随空间位置变化，背景山水仅作为远景；取消行走时屏幕抖动。
- 点击启程/暂停、点击目的地即自动前往；W/方向键作为辅助。保留旧桥影的按住摇橹操作。
- 苏堤落座连续包含靠近、俯看、转向、降低眼高与环顾，起身反向完成；同一空间中的椅子始终存在。
- 十景分别是长椅休憩、荷池风雨、月影追寻、桥面换岸、循鱼俯看、听声寻鸟、三塔取景、候云望峰、登塔环廊、听钟余韵。控制与反馈均区分。
- 古代点茶改为碾/调/击/观，古代听莺改为题画听景；现代龙井休闲与柳浪生态观察独立。
- 乌龟潭分入口、景行桥、曲水、开潭、侧望永福桥、浴鹄湾六段。永福桥三孔石梁结构；不宣称艺术化路线为实测导航。默认篷下坐客，可另切船尾体验摇橹；不允许舱内坐姿直接划船尾长橹。
- 墨滴深黑、有下坠形变与贴纸水迹，扩散形成整体流体遮罩；墨场中浮出线稿、淡彩，再连续进入画卷。不用散点或粒子聚合。
- 音乐为分景旋律、速度、音区与音色编排，切换渐变，手动开启、后台静音。Runway 已依用户指示弃用。Canva 连接无独立音乐生成/导出能力，采用本地原创编曲作为可运行音源，并记录边界。

研究：[乌龟潭](research/2026-11-10-wuguitan-immersion.md)、[十景](research/2026-11-09-westlake-real-scenes.md)。

验收必须观察真实前后遮挡与镜头路径，不能以按钮能点作为完成依据。此为艺术化空间重建，不作实景测绘、真实录音或历史建筑精准复原承诺。

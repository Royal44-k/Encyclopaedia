# V5 交付记录 · 2026-11-12

## 本轮改动

| 用户反馈 | 本版处理 |
| --- | --- |
| 品茶没有亲手操作 | 宋韵茶肆增加第一人称双手：抓住碾轮左右推磨，持壶移到盏上停留倾注，执筅来回击拂。粉末、水位和茶沫由手势进度驱动。保留按钮和空格替代操作。现代北山龙井与古代点茶分开。 |
| 全景与全屏混淆 | 「画卷全景」在独立展卷窗口完整显示原画，保持画面比例；「全屏」调用浏览器 Fullscreen API。首页、游览、穿越和宋卷均提供入口。宿主禁止全屏时显示明确提示，可在独立浏览器使用或按 F11。 |
| 布局遮挡 | 首页侧边文案改为同一布局组；团扇、题句和操作区分开；窄屏工具收纳；横向短屏重新安排首页；采莲操作时收起底部路段和十景导航。 |
| 墨滴造成黑幕 | 保留深黑墨滴，落点局部化；之后扩出细墨纹与亮水纹，以柔边逐渐显露黑白山水，再还原淡彩。取消全屏黑色遮盖。 |
| 湖西舟行缺少生命与结尾 | 增添树梢微动、草叶摆动、太阳碎光、船行波纹，分段出现水鸟、鸳鸯与飞鸟。终点减速靠埠，点击后连续起身、跨过跳板、上岸回望；船留在泊位。 |
| 沿岸内容不足 | 增加「沿岸风物与继续环湖」。湖西游后可分别转至花港、苏堤、柳浪和长桥机位。国宾馆作为湖西园林方位介绍，不把尚未核实的建筑与航线标成实测复原。 |
| 听莺粗糙且重叠 | 古代改为宋式绢面团扇：听风写柳、听莺点鸟、听橹添舟，画面渐显。现代保留柳岸循声找鸟。题句位于扇外；主要按钮可展开所需工具。 |
| 南屏钟声缺失 | 钟声用独立音效通道，点击即播放，不依赖 BGM 总开关。删除行走路段与山门任务。 |
| 双峰雾层厚重 | 全屏低透明柔雾横向漂移，点击静候后在约 12 秒内渐淡，远山逐渐清楚。 |
| 画中桥与模型重复 | 断桥、苏堤、柳浪不再绘制叠加的桥、道路、栏杆与树列。前行改变原画的取景与近远关系，转向保持原画连续。 |
| 采莲缺少手部 | 进入「画中采莲」，抓住花朵向自己拉近，手、花茎和花朵一起移动；完成后可题画笺。 |

## 验证入口

- `npm run check`：源码语法及 25 项状态、坐椅、透视、导览、手势与离船姿态检查。
- `node scripts/acceptance-v5.cjs`：真实鼠标手势、真实全屏状态、BGM 关闭时音效输出、墨色像素采样、完整实际时长舟行及上岸。
- `node scripts/layout-v5.cjs`：320×740、390×844、667×375、768×1024、1024×768、1440×960 的主要布局边界与碰撞检查，配套截图。
- `node scripts/regression-v5.cjs`：苏堤起身、晴雨雪、过桥、按钮/键盘兼容点茶与题扇。

测试的具体结果保存在工作区 `verification/v5/`。静态交付包包含运行文件与研究说明，测试脚本留在开发工程。

本轮已通过：25 项单元/状态检查、9 项浏览器主流程、5 项原功能回归、6 组尺寸布局，以及独立静态包的 5 项检查。十景另外逐一核对了 390 与 1440 宽度的标题和主控边界。八个转场采样的平均亮度约为 175—194/255，低亮像素最高占比小于 0.1%；这项数据用于排除整屏黑幕，不替代视觉审稿。钟声验证了 BGM 关闭时音频上下文运行且独立音轨有非零输出。舟行使用实际时间走到终点，再完成 6.5 秒离船动作。

## 调研与视觉边界

详见 [V5 研究记录](research/2026-11-12-westlake-v5.md)。核实了湖西水系、苏堤/花港/柳浪/长桥空间关系、鸳鸯调查、宋人茶事与绢面团扇。视觉组织参考实际访问的森林声音地图、百度 MEUX 团扇设计说明和 Codrops Water 实验页面；本轮没有逐帧复刻未经观看的 WebGL 动效，也未使用这些案例的图像或音频资产。

本作品仍是原画视点移动、程序绘制近景与手部动画的结合，不是实景扫描或完整自由行走的三维仿真。手与舟岸的程序造型仍有简化质感；钟声、鸟声、配乐为原创合成，并非西湖现场录音。没有使用付费 Runway；此前 Canva 接口能力限制未解除，本轮不把程序绘图或合成音效称为 Canva 输出。

V5 单独打包，保留旧版。未公开发布或代为提交比赛。

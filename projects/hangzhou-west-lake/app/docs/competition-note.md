# 《杭州西子湖 · 今夕入画》作品阐述草案

## 作品主张

西湖不只是一组可被拍摄的景点，更是一种人与山水相处的生活方式。《杭州西子湖 · 今夕入画》以“今日闲情、宋时烟火、湖西野趣”为三条叙事线，将观看长卷转为可以亲身参与的游历：在苏堤柳阴下走近长椅，坐下来望湖；在曲院风荷听一场雨；随深黑墨滴进入宋韵人间，在临水茶肆碾末、调膏、击拂；再回到当代，乘舟穿过景行桥，进入乌龟潭的湿地与曲水。

作品以现代西湖为首屏，将古今并置，但不混淆年代。今日重建塔身、现代茶室与湖西水路留在当代章节；宋茶和题扇作为经过研究约束的文化体验与原创叙事，避免将现代生活简单换装为古代。文化信息藏在“此景来处”与湖山寻路中，可随时查阅来源，也不打断观景。

交互强调身体与环境的关系。步行改变近景透视，坐椅有靠近、俯看、转身和降低视线的连续过程；行舟借助曲水、桥影和两岸遮挡显出空间；听钟与观鸟以停留和观察为核心。六幕导览为初次观看者提供清楚的入口，暂停与接手让观众始终保有选择。游历手记记录亲自完成的体验，画笺把个人题字与当下画面留作旅途记忆。

## 建议现场演示顺序

1. 首页停留片刻，介绍“现代为起点，古今往来”的主题，确认音量合适。
2. 点击“一湖三境”，在湖声设置中调整配乐与解说；六幕约 142 秒，另有资源载入与换幕时间。
3. 到宋茶或湖西段点击“我来游湖”，亲手完成一次操作，说明导览和自由游览共用真实场景。
4. 打开“湖山寻路”，选一个与上幕不同的景点；展示文化信息及来源入口。
5. 生成横向或竖向画笺，题字、落款并保存，展示游览的个人留存。

## 实际实现与材料说明

- 形式：浏览器互动长卷；原生 JavaScript、Canvas 2D 透视投影与 WebAudio；无第三方在线运行依赖。
- 图像：延续项目已有生成画稿与本地原创程序绘制，来源清单见 `assets/v2/sources.json`、`assets/v3/sources.json`、`assets/v6/sources.json`、`assets/v7/sources.json` 及既有研究记录。V4 的地图、画笺、岸线、植物细节与界面为程序绘制。
- 参照：qingming-riverside 的布局与游览机制；本项目既有说明未声称逐像素一致。MotionSites 仅实际参考公开 Loader Animation 的节奏，不将其列为墨滴特效资产来源。
- 声音：V7 背景采用 Charlie Huang 真人古琴独奏《平沙落雁》，按 CC BY 2.5 使用并保留署名，替代 V6 的合成循环。保留本地音效及 20 段既有中文解说；不称西湖实地录音或 Canva 音源。Runway 已弃用。
- 地理：基于真实景观与来源约束的压缩艺术空间；地图标注方位示意，不用作导航。

研究依据包括 UNESCO 西湖文化景观、杭州市档案馆、杭州文物保护导览、中国国家博物馆，以及杭州发布 / 西湖风景名胜区管委会资料，具体链接见项目研究与设计文档。

# 杭州西子湖 · 今夕入画 V7

当前归档版本 **7.0.0**（2026-11-13）。原生 JavaScript、Canvas 2D、Web Audio，无第三方运行依赖。

## 运行与构建

需要 Node.js 22+，在本目录执行：

```sh
npm start
# http://127.0.0.1:4173/
npm run check
npm run build
```

构建输出为 dist/；请使用 HTTP 服务器打开，不要直接双击 HTML。站点按网站根路径引用资源，部署到子路径前须配置根路径映射。归档本身不代表已启用 GitHub Pages。

## 当前体验

- 默认现代西湖：十景差异化游览、连续坐椅动作、龙井舒叶品饮、湖山寻路、横竖画笺导出。
- 墨滴水纹穿越宋韵长卷：人物与船家、点茶碾磨/注汤/击拂/捧盏、听莺题扇、手握扇柄送风。
- 乘舟与按住摇橹过桥衔接乌龟潭：启停行舟、第一人称摇橹、水鸟避让、减速靠岸、连续离船。
- 画卷全景与设备全屏为独立操作；首页含六幕「一湖三境」导览。
- 首次用户操作后播放古琴《平沙落雁》与解说，音乐跨场景连续，旁白自动压低配乐；湖声设置可独立关闭。20 段本地旁白保留。
- V7 手、杯、茶具、扇柄、橹杆使用相互注册的图层与连续动作，减少空握与换物跳变。

38 项单元测试由 npm run check 执行。已有完整 UI 流程、六种视口及静态资源验证记录位于 verification/v7/；归档时的重新检查见 ../catalog/archive-verification.json。

# 杭州西子湖 · 今夕入画 V5

现代十景、宋韵长卷与湖西乌龟潭，原生 JavaScript / Canvas / WebAudio，无第三方运行依赖。

## 运行

Node.js 22+：运行 `npm start`，打开 http://127.0.0.1:4173 。不要直接双击 HTML。

- `npm run check`：全部源码语法与 25 项单元测试。
- `npm run build`：生成可部署的 `dist/` 静态目录。
- `node scripts/acceptance-v5.cjs`：主要浏览器流程。
- `node scripts/tour-v4.cjs`：实际时间完整走完六幕导览。
- `node scripts/layout-v5.cjs`：320、390、667、1440 宽度下的布局。
- `node scripts/resilience-v4.cjs`：慢加载、错误重试、音乐偏好与渲染记录。
- `node scripts/regression-v5.cjs`：坐椅、天气、过桥、点茶与题扇回归。

浏览器脚本使用本机 Codex runtime 的 Playwright 和已安装 Edge，仅为开发依赖，不进入静态包。

## 体验

首页新增「一湖三境」：六幕约 142 秒，跨现代堤岸、宋茶与湖西舟行，导览可暂停、换幕与随时接手；声音默认关闭，可在开始前选择。导览不自动解锁游历手记。系统偏好减弱动态时，导览从暂停状态开始。

「湖山寻路」通过原创方位示意图选择十景或乌龟潭，查看场景来处。进入景点后「题一张画笺」可留字落款，保存 1800×1200 横笺或 1200×1600 竖笺。画面与题字在本机生成。手机的次级操作收在「游湖工具」。手记现在独立记录 17 段记忆，古今茶事与题扇分别收录。

首页默认现代，右上「画卷全景」完整展示原画，「全屏」独立铺满设备屏幕。点击十景进入画境；一键开始/停步、点击路段前往、拖动环顾。苏堤走近长椅、俯看转身、坐下环湖、连续起身。十景分别设有荷风、候月、两岸观景、游鱼、鸟声、三塔换位、候云、登塔、晚钟等体验。

点击「穿越 · 入宋」观看深黑墨滴与八段水墨转场。宋韵长卷保留 48 位不同居民、步态、乘舟、四时晴雨与按住摇橹过桥。宋茶支持第一人称手部抓握工具，左右碾磨、持壶倾注、执筅击拂；古代听莺为绢面团扇听景作画；现代茶室保留龙井舒叶与品饮。

首页「一棹入青境」或长卷右侧「卷尽 · 入乌龟潭」进入湖西章节，可启停行舟、穿桥、转头看岸、到船尾体验摇橹、隐藏界面观景并保存画稿。终点停船靠埠，点击起身后连续登岸，回望泊船；沿岸风物入口可转去独立环湖机位。配乐默认关闭，可手动开启，随景切换。

## 文档与表达

见 [本轮实景与设计调研](docs/research/2026-11-12-westlake-v5.md)、[V5 交付记录](docs/v5-delivery.md)、[V5 设计](docs/v5-design.md)、[比赛作品阐述与演示草案](docs/competition-note.md)、[乌龟潭实景调研](docs/research/2026-11-10-wuguitan-immersion.md)、[动效与声音来源](docs/research/2026-11-11-motion-and-audio.md)。

本作品为艺术化空间重建：几何近景、绘画远景与分层交互结合，非实景测绘或全自由三维世界。V7 配乐为 Charlie Huang 演奏的古琴独奏《平沙落雁》，按 CC BY 2.5 使用，署名见湖声设置。Runway 已弃用，运行时不依赖外部媒体服务。MotionSites 只参考实际观看的公开 Loader Animation 节奏，墨滴自行实现。

参考 qingming-riverside 的布局与游览机制，代码与画稿独立制作；未声称逐像素一致。详细测试与截图在 `verification/v5/`。V1–V4 包保留，V5 单独打包，未公开部署。

静态包完整解压后，可使用 Node.js 22+ 运行 `node start-preview.mjs`，打开 http://127.0.0.1:4174/；Windows 可双击「启动预览.cmd」。部署时仅需 index.html、styles.css、src 与 assets，预览脚本不必上传。

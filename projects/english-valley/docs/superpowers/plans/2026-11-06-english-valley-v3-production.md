## Goal

先完成同一三维世界的空间与美术样板，再交付C1雨后溪流完整探究链路；C2/C3复用同一世界扩展。用真实浏览器输出验证视觉目标。

## Architecture

一份场景布局和持久对象身份，多套相机，允许按地点分包。案例、虚构证据、权威来源、原始语料分别登记。环境预览、故事进程、实验快照三种状态分开。成果物与证据记录引用具体对象和方案版本。

## Tech Stack

拟用Blender制作可编辑模型和动画，通过glTF/GLB交付，TypeScript与Three.js/WebGL负责实时交互，DOM负责可访问字幕、日志与教学面板。正式开工程前锁定实际工具和依赖版本。本轮未验证安装环境或创建应用。

## Global Constraints

图1布局优先；只有一座主桥，工坊固定西侧。真实网格、材质响应和持续状态。主资产保留来源、可编辑源、单位、轴向、UV与材质、交互部件和运行时预览。通用低模只作灰模或合格远景候选。教学问题不以单一口号、全点亮、点击速度或关键词命中判优。原创故事不冒称真实案例。

## Review Focus

空间与近景材质；操作是否改变相关对象；英语是否帮助判断和交流。切镜头不能改变地标、水路、调查条件或已完成操作。模拟不能越界宣称真实水质、材料或照明安全认证。

## Task 1 · 连续空间灰模与镜头

建议产物：art/source/world-layout.blend、art/review/layout/、art/exports/layout-preview.glb。
- [ ] 按拟定锚点建连续地形，加同一人物尺度参照。
- [ ] 放置温室、工坊、树屋、花环与唯一木桥，连通步行路和东北至南侧水路。
- [ ] 建五个拟定镜头；统一调整布局版本，不逐镜头搬动地标。
- [ ] 输出俯视及三主视角，标出证据、相机和尺度。
- [ ] 核查上下游、桥头、门路可达和相机不穿模。

通过：同一模型支持总览与局部构图。灰模只验证空间，不冒充最终美术。

## Task 2 · 主资产与材质样板

建议产物：art/source/hero/、art/exports/hero/、art/review/materials/。
- [ ] 先做主温室：细框、构件连接、前厅与侧翼、内部、门、雨槽出口。
- [ ] 完成主桥、岸坡、石径及近景木材、石材、土壤、植被、水面。
- [ ] 用中性灯和艺术天光检查纹理尺度、粗糙度、颜色/数据贴图语义。
- [ ] 重新导入GLB验证；登记作者/来源/授权/改造、原点、部件、LOD与代理。
- [ ] 提交最近允许观察距离的近景图；修正塑料感、无厚度、玻璃排序与重复植被。

通过：近景成立，可操作部件独立；随后按统一规格补齐工坊、树屋和远景。

## Task 3 · 真实浏览器视觉样板

建议产物：src/rendering/、public/world/、art/review/browser/，随首个工程确定目录。
- [ ] 加载同一布局和真实GLB；统一曝光、色彩、环境、雾与阴影。
- [ ] 复现总览、溪边、操作三镜头，标注设备、分辨率、相机、天气和场景版本。
- [ ] 检查透明、反射、湿地、岸线、叶片、接触阴影与镜头连续性。
- [ ] 录制进入溪边、操作位、返回总览的连续画面。
- [ ] 代表设备记录帧耗时、draw calls、纹理负载、首载与上传时间，再定档位。

通过：实际浏览器达到批准视觉的空间、材质与光照方向；未测前不承诺固定FPS。

## Task 4 · C1完整交互链路

- [ ] 瓶罐清理只改变瓶罐；两种照片比较分别保留时间地点。
- [ ] 接入分轮访谈和追问；记录有效信息和未知，不自动宣判原因。
- [ ] 证据可引用修订；开放论证师生评价，封闭信息题自动核验。

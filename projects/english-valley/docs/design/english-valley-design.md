# THE ENGLISH VALLEY · 英语学习工坊设计方案

2026-11-06 · v0.1 · 待评审的设计，不代表已开发

> 历史草稿：用户新要求及 [v2 概念方案](concept-directions-v2.md) 优先。五站通关已调整为连续环境调查，完整流程建议多课时；本文件中的旧概念、素材范围与性能预算不得作为已确认制作标准。

## 目标与已知条件

用户明确：面向初三；从人教版九年级选择贴切主题；先广泛研究、准备素材和设计，再正式开发；采用 Web 与 Three.js/WebGL；高度贴近给定山谷图，突出美感、交互与趣味。

本方案选择人教版九年级全一册 Unit 13 **We're trying to save the earth!**，命名 **The English Valley / 英语学习工坊**。官方目录依据见研究记录；具体在校教材版次未提供，不能宣称逐页同步或涵盖所有新版要求。

设计者暂定：40 分钟综合复习课，教师投影引导为主，学生可课后单机探索；不用账号、不联网收集学生个人数据；桌面 1440×900/1920×1080 优先，兼容平板和手机。用户可调整这些假设。

核心体验：学生担任山谷环保行动小组，以英语观察问题、取得证据、解释改造方法并提出行动。每次完成任务，场景产生对应的可见变化；完成度记录“任务是否完成”，不能冒充能力诊断。

## 路线比较与建议

| 路线 | 收益 | 代价 | 本方案判断 |
|---|---|---|---|
| 真实 3D 山谷＋HTML/SVG 课件层 | 最接近参考，保留空间、遮挡、四季、真实点击；题目清晰 | 需要模型制作与性能调优 | **推荐，尚待用户确认** |
| 预渲染 2.5D 场景＋热点 | 更轻，快速展示完整美术 | 无法自然改变观察角度，空间交互有限 | 仅作低性能设备后备 |
| 全 3D 自由漫游游戏 | 探索自由 | 导航训练、镜头晕动、课堂节奏和测试成本增加 | 不适合首版主流程 |

## 视觉标准

目标图：`assets/concepts/english-valley-desktop-v1.png`，由内置 imagegen 以用户图为参照生成；仅用于美术目标评审。模型、动画、点击和成绩都必须后续实际实现。

### 必须保留

1. **镜头与构图**：正交或近正交的高位斜俯视。初始测试俯角约 48°、水平偏转约 35°，最终按截图调整。中心温室占场景主要面积；地面向雾山延伸。禁止改成漂浮圆盘岛。
2. **建筑关系**：温室中心；树屋位于后侧偏左；木作坊左前；圆形花圃正前；水池和桥右前；建筑间用石径连接，不能用随机散落几何体代替完整园林。
3. **材质**：暗绿金属细骨架、低反光浅绿玻璃、暖色木结构、灰米白铺地、分面树冠。玻璃后面应能看到种植台；必须有地基、门、楼梯、栏杆和屋顶接缝。
4. **光照**：一侧柔和日光、可辨接地阴影；山与远树逐层降低对比；界面文字不受雾影响。
5. **界面**：衬线大标题、象牙白四季条、深苔绿磨砂热点、极简底部导航；地形占初始屏幕至少 70%。无需营销区块或数据卡片墙。

### 色板与字体

| 角色 | 值 | 使用 |
|---|---|---|
| Evergreen | `#20382B` | 标题、正文、核心按钮 |
| Moss | `#58664B` | 低饱和热点、深树冠 |
| Sage | `#87947A` | 地形及中间层 |
| Mist | `#C1CAC0` | 远山与空气透视 |
| Parchment | `#F3F0DF` | 课件面板及按钮文字 |
| Timber | `#A77D50` | 木作坊、木桥、暖色细节 |
| Blossom | `#CFA5AA` | 少量春季花瓣 |

标题 Cormorant Garamond 600；教学英文 DM Sans 400/600；中文 Microsoft YaHei/PingFang SC/Noto Sans CJK SC 回退。仅标题与地点标牌使用英文大写，正文正常大小写。桌面正文 18–20px，投影模式 24px，行高 1.6；界面标签至少 14px，触控区域至少 44×44px。

半透明标签必须有足够深的底色，不能只在色板上计算对比度；需在实际最亮和最暗背景上检查。正文目标对比度至少 4.5:1。

## 场景与学习地图

| 地点 | 标签 | 任务 | 场景反馈 |
|---|---|---|---|
| 右前池塘 | LISTEN / 听见变化 | 听校园池塘报告，辨认问题、已做行动、后续建议 | 清除少量漂浮物，水面恢复清亮 |
| 正前花圃 | WORDS / 词汇花圃 | 在行动语境中使用 recycle、reusable、reduce 等词 | 对应花床长出新苗 |
| 左侧木作坊 | BUILD / 句子工坊 | 组合被动语态，辨认现在完成时与情态表达 | 废木料变成长椅或花箱 |
| 后方树屋 | READ / 阅读树屋 | 阅读原创环保项目短文，区分证据与推断 | 树屋路灯亮起，记录本增加证据页 |
| 中央温室 | ACT / 行动温室 | 完成 80–100 词校园环保提案并按量规自评/互评 | 温室打开门，显示行动卡；只修复温室区域 |

点击建筑本体与对应标签进入同一任务。首版不加入强制长距离走路、角色控制或战斗。地图允许所有站点随时进入；推荐路线可高亮，教师可跳站。自由探索不造成课程锁死。

初始状态：园林结构完整但池塘有少量漂浮物、花圃部分空缺、工坊材料未整理、树屋和温室灯关闭。局部完成：仅对应站点改观。全部完成：五个 completed 全为 true 才显示全景修复、完整记录本和结束提示；先做 ACT 不提前解锁全景完成态。设计目标图展示的是完整园林的美术形态，左下 0/5 是布局示意，不能把它直接当作精确初始状态截图。

## 课时建议：40 分钟

导入观察 3 分钟；LISTEN 6 分钟；WORDS 5 分钟；BUILD 6 分钟；READ 8 分钟；ACT 9 分钟；退出卡 3 分钟。任务完成后可重听、重做或查看解释。教师模式有“显示答案”“下一站”“回地图”“重置本课”，答案默认折叠；只在本机操作，不构成联网课堂管理系统。

阅读和写作篇幅按综合复习设计，不把五个地点当作五节新课同时讲授。支持跳过部分模块或将 ACT 移为课后作业。

## 交互与状态

主链路：载入 → 地图 → 地点聚焦 → 活动 → 提交 → 解释与重试 / 完成 → 返回地图。每站保存 draft、attempts、completed、answerRevealed；页面刷新保留本机进度；“新一轮课堂”提供明确确认并可导出当前结果。

桌面任务面板宽 420–520px，偏右打开，镜头把建筑移到左侧留白。长阅读可切全宽阅读模式；关闭后恢复地图位置和触发控件焦点。手机用下方抽屉，顶端保留场景约 35–40% 高度；文字任务可展开全屏。避免右侧面板遮住地图的唯一导航。

词块排序同时支持拖拽和点击选择→放入槽位→撤销；键盘可用按钮移动次序。错误答案保留，给定向提示，不随机抖动整屏或倒扣生命。开放写作只给词数及人工量规，不能用关键词匹配宣称评分准确。

声音默认静音，点击开启后才播放环境音；听力按钮具有独立播放/暂停/重听。准备的合成 WAV 为原型音频，进入课堂前需教师试听；无音频设备时可切文本支持，界面明确这是阅读替代，不能记作听力测评。

## 动效分镜

| 触发 | 动作与目的 | 目标时长 | 可打断/减少动态 |
|---|---|---|---|
| 首次进入 | 雾淡入后显示地点入口，建立整体空间 | 800–1200ms | 可跳过；减少动态立即完成 |
| 指向地点 | 标签升起 2px，建筑轻微提亮 | 160ms | 无悬停设备用选中态 |
| 点击地点 | 相机平移与少量缩放，保持朝向 | 650–850ms | 可被新选择取消；减少动态用 100ms 淡变 |
| 打开题目 | 面板淡入并移入 16px | 220ms | 关闭后回收焦点 |
| 句子组装 | 词块进入槽位，SVG 指示主语/谓语关系 | 250–400ms | 点击路径等价 |
| 任务完成 | 该地点局部修复、长苗、亮灯 | 900–1400ms | 只播放一次，可直接继续 |
| 切换季节 | 光照与植被配色过渡；不重置进度 | 900ms | 快速点击只执行最终选择 |
| 日夜切换 | 天色和窗灯过渡，正文对比度保持 | 900ms | 夜间不要全屏 bloom |

春：淡粉花与新绿；夏：深绿与暖日光；秋：麦金与赭红；冬：灰绿与薄雪。四季只换材质与少量实例，不加载四套完整世界。粒子、风、水纹在活动面板打开或页面不可见时暂停/降频；减少动态模式关闭。

## 技术建议与资产管线

建议 React + TypeScript + Vite + Three.js，使用 React Three Fiber/Drei 管理场景和 DOM 热点，GSAP 编排镜头与 SVG；仅建议，尚未初始化工程或安装依赖。运行时基线 WebGL2，WebGPU 只作为以后可选增强。

模块：Scene（地形/建筑/季节/热点）、Learning（题目与反馈）、LessonData（原创内容）、Progress（本机状态）、Accessibility（键盘/减少动态/2D 导航）。内容与场景按稳定 stationId 关联，换课不重做美术。

模型采用 GLB；建筑按定制图纸制作或使用参数化几何；背景自然资产从已取得 CC0 包选型、统一缩放和材质。不能把下载的 Nature Kit 说成完整温室场景。温室窗框合并/实例化；玻璃先用可控透明材质验证排序；避免全场高成本折射。

本地字体与音频，避免课堂每次依赖外部 CDN。纹理优先小尺寸并打包；重复石板/树木实例化；资源随课件本地部署。首版进度用 localStorage，提供 JSON 导出和清除；不实现班级云端同步。浏览器清理数据后进度会丢失，界面需提示。

## 目标预算与验证方法

以下是验收目标，尚未测量：桌面约 60fps，中档平板至少稳定 30fps；首个可操作场景总传输目标 ≤8MB（不含按需音频），完整首课目标 ≤20MB；场景可见面数先控制在约 150k，draw calls 目标 ≤120；DPR 桌面最高 1.75、移动 1.25；仅主方向光投影，默认 1024/高档 2048 阴影贴图。

正式验收记录设备、浏览器、分辨率、冷启动缓存条件及网络条件；用真实交互测帧率，不凭开发机截图宣称性能达标。低档降低粒子、阴影和 DPR；WebGL2 不可用时提供静态地图＋全部 HTML 任务，明确显示简洁模式。

视觉截图集合：初始春日、冬夜、热点选中、听力打开、句子反馈、阅读全宽、完成温室、手机 390×844。与原图和目标图并排核对：镜头、温室轮廓、路径关系、材质、光向、留白和文字。

## 完成标准与阶段顺序

1. 设计评审：确认此目标图、课程主题与课堂模式；本次交付覆盖研究、素材盘点与设计。
2. 开发前美术准备：制作温室、树屋、木作坊等定制 GLB、统一材质，完成地形与路径样板的基础渲染检查，试听并准备课件音频；所需资产准备完毕再开始正式课件工程。任何“方块代建筑”的方案不得进入下一阶段。
3. 正式开发与教学闭环：先完成池塘听力→提交→解释→环境变化→刷新保留，再扩展四站。
4. 完整首课：五站、四季昼夜、教师模式、音频、任务回顾、键盘与手机。
5. 浏览器验收：正确性、视觉、流畅度、静音、减少动态、资源加载失败、存储失败、刷新恢复、重复点击与重置。

本阶段不承诺已完成这些功能。后续主要不确定性是定制建筑质量、课堂实际设备性能和学校教材版次。先以一节完整可用的示范课验证，再扩展课程库。

## v6.1开发准备度与润色

当前判断和下一批边界见[开发准备度与实际打磨](readiness-and-refinement-v6_1.md)。本轮依据[戏剧性复核](dramaturgy-polish-review.md)、[课堂复核](learning-readiness-review.md)与[工程复核](readiness-engineering-review.md)，落实如下修订；这些复核中的“建议”和旧数字不作为当前执行源。

| 本轮缺口 | 已落实的修改 | 当前依据 |
|---|---|---|
| 多位角色像同一位主持人，过早解释意义 | 十四句原位改写及动作调整；保留事实、困难与复杂表达，T12不添加不存在的共同经历 | 各章主表与语言理解支持 |
| 多章都用空白、下次和问题收尾 | 六处场面补具体动作与即时用途，查明的谜可以结束，创作可以真被看见和试用 | T01、T02、T05、T08、T09、T11 |
| 51条条件分支散在说明里 | 统一为独立编辑表，342条主线/分支/示例都有结构化记录 | 分支对白表、生成索引 |
| 信息差没有可分发材料，操作完成被误当学习 | 新增英文角色卡、实际产出、支持方式与观察记录；口述自报和教师观察分开 | 首课课堂执行稿 |
| 四个艺术片段不能证明完整课例 | 选定T03内部桥位回访旅程；四类艺术样板保留为专项验证 | 第一旅程交接与流程JSON |
| 教学入口、证据编号、模型比较互不一致 | 统一桥位独立初态、E01/E02/E03及Mei E04、无覆盖固定基线；不足资料只能继续访查或保留未解 | 首课稿与交接合同 |
| 放置、试验、复查和恢复缺明确提交点 | 声音/字幕不提交行动；实际放置、版本快照、暂停恢复与保存失败分别规定 | 第一旅程交接与流程JSON |
| 美术效果难以对照验收 | 补五个同世界镜头及三段连场试读，记录材质、接触、地理和情绪变化 | 视觉与声音导演稿 |

对白条件与流程合同另做针对性复核：关注清理发生在不同节点时的反馈、访谈信息中断、移动中切场、试验修订意图与结尾事实。复核只判断声明式设计是否自洽，正式工程仍需实际执行与回归检查。

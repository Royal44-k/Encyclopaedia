## 3. 可直接进入案例的语言行动

下列句子均为项目原创；来源核查范围以 JSON 的 `supportScope` 为准。

| 教学动作 | 关联条目 | 案例中的用途 |
|---|---|---|
| 先描述，再推断 | LEX03、LEX17、LEX18 | 看见垃圾或亮灯是观察；可能的土壤来源、照明是否过亮仍需调查。 |
| 请求补充信息 | LEX02、LEX22、LEX29 | 向园丁追问雨前发生了什么；向工坊成员征求标牌位置建议。 |
| 作有效比较 | LEX12、LEX13、LEX26、LEX27 | 对照雨前／雨后、上游／下游资料，并记录时间和位置。 |
| 区分行动与口号 | LEX08–LEX11、LEX20–LEX25 | 从“再用有好处”推进到状态检查、具体用途、操作和维护安排。 |
| 权衡而非二选一 | LEX21、LEX34、LEX35 | 夜间照明保留真实使用者需求；物品看起来结实也不跳过检查。 |
| 表达尚未知道 | LEX14–LEX18、LEX28 | 对证据不足的 claim 保留意见；承认没有检查的部分。 |
| 计划与反思 | LEX25、LEX32、LEX33、LEX36 | 再观察、再检查、承认资源约束并修正初始看法。 |
| 合作与号召 | LEX30、LEX31 | 发出自愿参与邀请、提出自己能承担的具体任务。 |

建议将每次互动的主动输出控制在 1–2 个重点句框，其他词语按需展开。core 条目也可能含词典标为 B2 的词，如 evidence；将其列为 core 是因为它对案例关键，并配有释义和示范，**不代表全体初三学生应已掌握**。stretch 可在教师模式关闭，允许用 idea、we think、please help 等更简单表达完成同一思考任务。以上分层与界面建议为本项目设计判断，尚未经过课堂验证。

三个原创示例分别体现不同的思考，不要求学生只说统一口号：

- C1：*Do we have evidence that the soil came from this area?* ——追问证据，LANG01 只支持词义与结构。
- C2：*Even though the box looks strong, we still need to check its base.* ——承认外观，再提出检查，LANG15 只支持让步结构。
- C3：*Although this path is quiet, some people still use it at night.* ——保留使用者需求，LANG15 只支持让步结构。

## 4. 语言质量核对与待办

| 核对项 | 本轮处理 |
|---|---|
| evidence 的数 | 证据义按不可数处理，不写 an evidence / evidences；LEX02 采用 evidence that 从句。依据 LANG01。 |
| litter / rubbish / waste | 不把三者机械互换；标明语境义和词性，避开动物一窝、贬低他人等无关义。依据 LANG02–04。 |
| reuse / recycle | 词典存在宽泛近义用法，课件按具体操作区分“继续使用物品”与“材料回收处理”；环保分类不由词典单独决定。依据 LANG05–06，机制须另查 ENV03。 |
| claim | 可数名词／动词分开；claim 不自动等于谎言；LEX15 的绝对化广告是待质疑材料。依据 LANG08。 |
| suggest | 采用 -ing、that 从句、wh 从句；不写 suggest somebody to do / suggest to do。依据 LANG09。 |
| 情态推断 | might/could 保留不确定性；must 为说话者高确信判断，安排于日常场景，不包装成生态证明。依据 LANG10。 |
| 被动与时间 | 现在、过去、将来被动分别对应流程、日志、计划；已计划不等于已完成。依据 LANG11。 |
| 完成时与过去时 | yesterday 配一般过去；already/yet 用于当前任务进度；LEX36 的反思衔接是原创，来源只支持时态对照。依据 LANG12。 |
| 礼貌与邀请 | 请求、邀请、主动帮助分开，不把所有话术都叫“建议”。依据 LANG13。 |
| 条件与让步 | 不将 hypothetical 当过去事实；although 不与 but 成对；even though 不与 even if 混为一谈。依据 LANG14–15。 |
| 英美变体 | 正文以英式书写为基线；接受语境正确的 trash/garbage、compare to 等，不做机械唯一答案。 |
| 尚未完成 | 独立英语教师审校、教材版本／页码对齐、学生可读性小样、配音与字幕审听、开放口语评分容错设计。 |

环境词 sediment、runoff、buffer、rain garden 等尚未进入本 36 项，避免在缺少逐项语言来源时伪称已核验。它们可作为图片标签或教师注释，后续逐项扩展语义与发音来源；本轮不会把所有景观标签变成必背词。

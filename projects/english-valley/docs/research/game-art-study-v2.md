# English Valley · 游戏级 3D 美术与空间体验研究 v2

研究日期：2026-11-06。范围：在用户给定的微缩花园基础上，提高真实空间、材质可信度、探索体验与制作精度；为三版概念图提供可追溯依据。本文不代表课件已实现，也不把 AI 概念图当成实时渲染证明。

## 结论

建议把“逼真”定义为**空间、材料、光照、生态和操作结果都可信**，再选择表现风格。可以保留低饱和花园与精炼轮廓，同时增加精细建筑构造、材质差异、自然过渡和有因果的世界变化。真正需要选择的是观看和参与这个世界的方式：精工微缩总览、可探索的自然主义山谷，或近人视角的实地调查。

目前取得的证据是官方网站、开发者文章、公开源代码说明和渲染文档。本轮没有完成这些案例的实时浏览器操作与性能测量；不能声称复现了其视觉效果、测试过所有交互或能够在学校设备上达到同样帧率。

## 从现有微缩图走向高精良制作

以下是本项目的美术判断，不是对上述案例的未验证技术归因。

| 层面 | 制作标准 | 最容易出现的退化 |
|---|---|---|
| 空间 | 主温室、树屋、工坊、水系形成可理解的地理关系；坡地、排水沟和石径真正连接 | 把建筑和树摆在平面上，像散落的素材样品 |
| 几何 | 温室有结构节点、窗框厚度、屋脊、门槛和内部种植台；木桥有支撑、栏杆与接岸 | 放大简单方块或单层透明壳当作建筑 |
| 材质 | 湿石/干石、旧木/新木、玻璃/金属、土壤/苔藓具有不同粗糙度和尺度 | 所有资产只改同一种绿色，表面像塑料玩具 |
| 光照 | 建筑遮挡、接地阴影、间接光、远景雾的方向一致；夜间窗灯有合理来源 | 用过量 bloom、强景深、过曝太阳掩盖细节 |
| 植被 | 形成树冠、灌木、地被的层次与簇；道路和任务工具周围让出可读区域 | 随机满铺同一株树；高频叶片遮住线索 |
| 水与天气 | 水位、流向、岸线、雨后湿痕和修复前后状态一致 | 学生捞起一只瓶子后，全部污染与浑浊立刻消失 |
| 运动 | 风、叶片、水纹、窗门和角色动作节奏协调；操作有接触、阻尼、完成态 | 所有物体同频漂浮、镜头不停旋转、粒子抢占注意力 |
| 可玩性 | 观察点、可操作物、证据物能区分；交互不依靠只有鼠标才有的悬停 | 景色很美但不知道哪里可操作，或每个物体都是弹窗按钮 |

### 为什么现有低多边形素材包只能承担部分美术

当前基础自然包适合远景植被、重复小物和构图测试。它不含本项目所需的独特温室、调查工具、可拆装环保设施及其状态组合。仅做调色不能补出结构细节、统一物理尺度、近景材质、动画枢轴和线索功能。

因此不是弃用已准备资源，而是分级使用：**主建筑与手边物件定制；中景资产重做材质和轮廓；远景资产可简化并复用。** 是否适合近景应由目标镜头实际渲染决定，不由资产名字或文件大小决定。

## 三个概念方向：同一世界、不同参与方式

三版都保留参考图的山谷、玻璃温室、木作坊、树屋、石径、池塘与花园。共同故事起点应是“雨后池塘发生异常，需要找出原因”，而不是一个已经完美修复的展示园。概念图只展示一个明确调查任务，避免塞进十阶段教学清单。

### 精工微缩温室

- 相机：斜俯视总览，接近原参考；温室为视觉主角，水道和可达路线可读。
- 美术：低饱和鼠尾草绿、木与石的精细纹理、薄而真实的玻璃反射；形体仍精炼。
- 核心动作：学生从地图看见雨后异常，选择沿水道调查。点击后进入该地点近景，保持空间连续。
- 优点：最保留原图气质，便于教师投影调度与理解全局。
- 代价：观察近景细节需要二级镜头，不能让全部证据只存在于远景小像素中。

### 可漫游的自然主义山谷

- 相机：较低的斜视探索镜头，沿道路看到远处温室，前景有可检查的水渠、土壤和鸟类踪迹。
- 美术：精致风格化自然主义，植物和土地更具生态层次，保留克制的色彩，不改成高饱和儿童卡通。
- 核心动作：顺路访谈园丁、对照记录、拍摄证据、回到地图制定方案；保留短路线和一键返回。
- 优点：发现感与人地关系更强，适合观察—访查的教学链路。
- 代价：需要处理路径、相机遮挡和更大范围的资产一致性；不能把移动难度作为英语任务门槛。

### 近人视角生态调查站

- 相机：站在池塘木栈道/温室边的调查视角，前景样本、量筒或透明浊度管与野外记录本可操作；仍能看见山谷主建筑。
- 美术：更接近精细 3D 游戏的材质与光，湿木、玻璃、石岸、植物的层次明确；场景保持温暖而非灾难写实。
- 核心动作：对照上游和池塘样本，阅读英文标签，记录差异，提出下一步证据需求；工具读数采用明确标注的教学模拟。
- 优点：动手感、临场感和“用英语观察”最强。
- 代价：近景资产质量要求最高；不宜一直锁在第一人称，应可回总览并支持固定观察点。

三版的区别不应只是天气与颜色。每版需要改变相机、空间层级、任务入口与操作焦点；三版仍属于同一个设计世界。可以在选择后融合“微缩总览＋近人观察”，但应先选主导美术和镜头语言。

## 美术资产落地管线：选择之后再进入生产

1. **锁定风格圣经**：选定概念图后，整理相机、轮廓、色板、材质球、日光/阴天/夜景、植被分层、UI 标注规则。补一张主建筑近景和一个任务状态对比，避免只凭一张远景图开工。
2. **空间与资产设计**：先画可行走/可观察区域、上下游关系、遮挡和任务路线；出温室、树屋、工坊、工具、环保设施的正侧视和部件表。任务状态至少包括未检查、证据已记、操作中、修复后。
3. **代表性美术样板**：只做温室入口—石径—一段水岸，必须同时包含玻璃、木、金属、石、植物、水和一个手边工具。用真实网格和材质检查距离、色彩、光照、可读性；概念图不能直接充当运行背景以冒充这一环节。
4. **制作可交付资产**：保留可编辑源文件、统一米制尺度、原点/枢轴/命名、UV、材质通道、碰撞代理、可操作部件、需要的动画与 LOD。静态美术和需要改变的对象分离，避免一整块无法操作的模型。
5. **真实渲染比对**：同一镜头下对照概念图核对形体、玻璃层次、植被密度、光向、材质尺度；再检查相邻镜头与夜景。美术资产通过后，再进入正式课件功能制作。
6. **基于设备确定预算**：记录学校实际设备/浏览器/分辨率，在代表样板里逐项测阴影、透明、水面、植被、后处理与资源加载开销，再制定预算。暂不将任意面数、资源大小或 60fps 当作已保证指标。

烘焙、PBR、实例化、压缩和 LOD 都是可选手段，不能单独保证“游戏级”。质感首先来自一致且可读的美术判断，最终仍要由实际渲染与交互验收证明。

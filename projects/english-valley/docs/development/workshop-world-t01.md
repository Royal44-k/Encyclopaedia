# T01 工坊与同一件作品 · 三维模块交接

2026-11-08。本模块依据已批准的 T01 详稿、共同世界布局与 Iris/Sam 人物稿制作。它使用现有 Three.js 场景、材质光照、工坊建筑和谷地路径，没有增加另一套孤立世界。

## 实际实现

- 在西侧工坊正面加入木条工作台、榫接和金属销、承重横档、零件盘与纸笔。作品包含木底座、金属支杆与连接轴承；零件由实际支撑承接。
- 主体可用金属圆环、旧罐和分叉枝条；装饰可用瓶盖、折叠布片和纸扇。圆环有连续曲面、高光与磨损线，旧罐有卷边和环筋，布片有下垂褶形与织纹，纸扇有实际折面。
- 同一个 `work.t01.player` 对象在工作台、小路展位、花圃环路展位间移动。只保留一个作品对象，移走后原位没有复制品。展台与演员位置经过图片检查，已移出花床和桌面碰撞区域。
- 自动轴转仅接受轻主体与活动连接；罐体不通过渲染器偷做运动。停止后保留用户设定角度。减少环境动态不会禁止用户主动启动的作品运动。
- Iris 使用当前人体基础网格，依人物稿设为灰蓝外套、米色内衫、速写册、较年轻体态与不同发型。默认 C1 中隐藏；只有进入 T01 才加入工坊。Sam 复用同一角色模型。
- 观看角度改变时，Iris 会走到相应观察位。跨展位沿现有路线移动镜头和人物；同地点换角度采用短路径。桌面特写与同伴讨论采用不同景别。
- 展签属于作品模型；空标题仍为空线，不强加标题。`captureArtwork()` 使用当前作品和同一谷地渲染真实记录图片，返回 JPEG，不生成概念图。

## 接口

`setWorkshop(state)` 启用 T01，更新作品与角色，返回镜头/人物到达的 Promise。`stage` 支持 entry/make/share/place/end，`view` 支持 front/side，`moving` 为用户启动状态。相同场面重渲染不重复导航。

`workshopView(view)` 切换观看角度，返回到达 Promise；自动对白应等待完成。`setWorkshop(null)` 离开专用模式。

`setArtwork(artwork)` 只恢复共享作品，不更改 C1 镜头或同伴。非 T01 模式只展示已展出或明确暂存作品，草稿不凭空成为展品。字段定义与根集成提供的作品合同一致。

`captureArtwork()` 返回 900×600 当前真实作品的 JPEG data URL，拍摄完成后恢复原视口、相机和像素密度。

## 本模块验证

[5项场景测试](../../app/tests/workshop-scene.test.mjs)通过：唯一实体迁移、未确认作品隐藏、无主体时不悬浮装饰、连接类型与运动约束、有限且可释放的几何数据。

[独立构图检查](../../app/artifacts/t01/workshop-scene-check.json)没有页面异常。桌面正面、侧面、花圃及390px窄屏画面见同目录的 `workshop-scene-*.png`。这些图片带占位布局，明确是渲染器构图研究，不冒充最终应用 UI 验收；完整交互与 C1 回归由主集成检查。

## 仍需精制的边界

布片是有织纹的固定褶形，并非实时布料模拟；连接采用有限合法接口，不是任意物理拼装。运输目前通过同一对象位置与演员沿路过渡表达，没有手部搬运 IK。Sam 的接盖/伸手后收回、眼神与精细表情尚需专门动画。现有角色皮肤、发丝、衣褶与音素口型未因本模块完成而达到最终写实游戏品质。新增材质均为项目程序制作，无新增外部图片或模型许可。

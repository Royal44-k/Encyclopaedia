# T01 · 从空展台到第一位观众

2026-11-08。本轮针对“学生界面混入制作说明、各操作像独立演示”的反馈，完成旧物奇想展的连续剧情。预览：<http://127.0.0.1:4173/?module=T01>。已有页面需要刷新以载入新版本；旧作品可从“带回工坊修改”进入新一轮交流，原展签保留。

## 学生实际经历

Iris 在准备花园展览，小路旁还空着一个展台。Sam 拉开旧零件抽屉，学生选圆环、铁罐或枝条时，听到该物件以前的用途或来历。学生组合、旋转、试连接，做好后叫 Iris 过来。

她不会对每件作品说同样的话：圆环让她想到窗，铁罐让她想到花盆，枝条让她想到小树。作者可以请她换一边看、演示可动部件，或保留另一种联想。角色的后续回应发生在换位到达或实际转动以后。静态铁罐没有转动分支。

Iris 请作者为观众写展签。学生可以留下自己的英文、选择借展规则，也可以留白。随后带着同一件作品去花园，分别试小路和花圃的位置。只有到达并从观众位置看过，才能确认展出。原工作台不会留下作品副本。

Iris 成为第一位观众。学生可以带她再看一次作品，也可以问她是否留下旧物。后一个话题谈到她用旧饼干罐装画笔；Sam 回应，继续使用即可，不必把每件旧物都做成展品。环保内容在这里对应具体的生活选择。完成这段交流后，展览才有完整结尾、实景照片和可下载记录。暂存则保留未完作品，不冒充完成展览。

## 本轮实装

- 状态由五个散点扩展为制作、首次观看、作者回应、展签、试展、观众交流、结尾；未发生的观看不能跳过。
- 三种材料的首次联想、三种作者回应、两处真实展位和两类观众交谈均已连接；自由文本原样保存，不假装理解学生任意输入。
- 增补 20 段原创角色录音，当前音库共 39 段；Sam 与 Iris 沿用各自声线，工坊/展出分别使用现有音乐。进场自动播报，逐句重听。
- 删除学生界面的“清洁检查过”“不是溪流刚捡的”“没有标准答案”“AI只响应预设”等制作或评价说明。课堂参考放在教师入口，技术边界放在交付文档。
- 新回复在窄屏自动打开完整对话；普通设置和界面刷新保留当前视图。对白不使用内部滚动。
- schema 1 作品只在实际修改时迁移；材料、作者原文、许可、身份、撤销记录保留。旧完成记录不补造曾经发生过的观众交流。另一标签页的新版本不会被静默覆盖。

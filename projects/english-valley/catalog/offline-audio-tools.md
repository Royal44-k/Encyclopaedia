# Offline audio production tools

This folder contains project-local Python packages and the official Kokoro ONNX model/voice vectors used to render English Valley audio. It is not a runtime web dependency and should not be published or committed as application content. Bundled playback assets are in app/public/audio. Source, licenses and hashes are recorded in docs/development/audio-assets-v2.md and app/public/audio/asset-provenance.json.

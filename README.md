## 归档规则

- 每个专题保留原项目目录与内部相对路径，源文件、交付文件、图像和质量检查记录均可追溯。
- 当前版本以专题首页为准。历史目录中的“final”“当前版本”等文字描述其当时状态，不覆盖专题首页的版本指引。
- [归档说明](archive/README.md)记录范围、去重方式与迁移限制；[文件清单](archive/asset-manifest.csv)提供 SHA-256 校验值。
- 重复 ZIP 包以[逐项索引](archive/package-index.json)归档，包内每个文件都可定位并校验；通过[重建脚本](archive/restore_packages.py)恢复下载包。
- 第三方报告与文献保留原作者及权利归属；仓库原有 [LICENSE](LICENSE) 未作修改。详见[来源说明](collections/ai-organization/sources/tencent-2026/README.md)。

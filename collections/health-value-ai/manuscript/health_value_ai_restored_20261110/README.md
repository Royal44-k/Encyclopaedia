# 中英文图文稿：回滚改进版

日期：2026年11月10日。

本目录为当前使用版本。以 `health_value_ai_final_20261109` 图文版为基础恢复双栏正文、图表位置和情境插画；随后制作的 `health_value_ai_nhb_20261109` 单栏版已停止使用，原文件保留归档。

## 阅读与编辑

- `Health_value_AI_ZH.pdf`：中文阅读版，14页。
- `Health_value_AI_ZH.docx`：中文可编辑稿。
- `Health_value_AI_EN.pdf`：英文阅读版，14页。
- `Health_value_AI_EN.docx`：英文可编辑稿。

每种语言保留11幅图、3张可编辑表、3个公式及26条参考文献。DOCX中的公式为原生公式，引文为原生上标。PDF与Word分别生成，个别换行可能不同，内容和所在页一致。

## 本轮调整

首页明确设置“摘要／Abstract”，补入六个对应的中英文关键词。引文与文末著录统一采用Nature数字编号样式；上标通常不带方括号，多来源按组排列。同一来源复用编号。表格引文放在研究名称后，避免与样本量混淆。中文正文首行缩进两字，图表交叉引用保持正常基线。

参考文献统一期刊缩写、斜体、卷号加粗及悬挂缩进；每条完整排列，避免跨栏拆开。中文引文与前文保持连排，避免孤立编号。原有正文、摘要、图注及数据未因排版改写。

格式选择、官方依据、国内本科论文适用规则见 `格式与引文说明.md`。本稿采用既有图文阅读版式；所选引文样式不等于所有目标期刊的完整投稿模板。

## 配套材料

- `figures/en`、`figures/zh`：两种语言各11幅图的SVG、PDF、300 dpi PNG。
- `illustrations`：原有三幅情境插画及生成记录。
- `references.json`、两份CSV：沿用原稿的文献记录和绘图数据。
- `content_bilingual.json`：中英文对应正文。
- `build.py`及绘图脚本：本地重建文件，使用Windows系统字体。
- `qa/checks.json`、`qa/final_audit.json`、`qa/visual_review.md`：结构、文本及版面检查结果。

本轮工作范围为版本恢复、引文规范化与版面修正；没有新增实验，也没有把概念框架标记为已经得到实证验证。投稿要求仍以最终选定期刊及文章类型的作者指南为准。
